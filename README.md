# Little Learners Club

An interactive educational website for young children to learn the alphabet, numbers, and nursery rhymes.

## Live Site

https://mmobin-k.github.io/Kids_Interactive_Website/

## Features

- Alphabet A–Z with images and audio
- Numbers 0–10 with images and audio
- Nursery rhymes with audio playback
- Quick quiz
- Contact form
